# Sidebar Button

Телефонные доработки сайдбара BB поверх Mobile Layout из плагина Superhuman
([rebryk/bb-plugins](https://github.com/rebryk/bb-plugins/tree/main/superhuman)).
На телефоне Mobile Layout прячет родную кнопку сайдбара и оставляет только
свайп от левого края.

- **Кнопка левой панели** в нижней панели треда (первая слева) и на карточке
  главной (зеркально кнопке правой панели). Клик нажимает спрятанную родную
  кнопку BB, поэтому сайдбар открывается так же, как от свайпа.
- **Свайп по строке треда в сайдбаре**: вправо убирает из «Ждут тебя», влево архивирует.
  Снятие ожидания показывает галочку и доступно также в меню треда;
  новое событие агента снова поднимет тред в группу. Закрепление остаётся в меню. Строка едет за пальцем, под ней дорожка с
  иконкой; когда отпускание сработает, дорожка заливается и телефон
  щёлкает. Архив уводит строку влево и схлопывает её. Действия родные из меню
  треда, с подтверждением для треда с дочерними и Undo; если BB отказал,
  строка возвращается. Быстрый флик срабатывает с половины пути.
- На строках отключён свайп BB, закрывающий сайдбар: его можно закрыть
  свайпом вне строк или тапом по странице.
- **Кнопки Recap и Follow-ups слева от микрофона**, на десктопе и телефоне,
  потому что их автозапуск выключен. Звёздочка пишет сводку треда сейчас.
  Пузырь включает Follow-ups только для этого треда: подсказки появляются
  сразу и после каждого следующего хода; повторное нажатие выключает их и
  стирает. Разового запуска у Follow-ups нет. Кнопки вызывают RPC самих
  плагинов (`recap_generate`, `followups_set_enabled`).
- На телефоне прячет кнопки Recap и Follow-ups из нижней панели треда: их
  карточки над полем ввода и так видны, а панель держит один ряд кнопок.
- Всё работает только при `html[data-phone-layout]` и
  `(width < 48rem) and (pointer: coarse)`, как у Mobile Layout. На десктопе и
  iPad в полный экран ничего не меняется.
- Слоты `experimental_threadHeaderAction` и `experimental_appOverlay`
  экспериментальные, а разметку BB плагин находит по `data-*`, так что
  обновление BB может это сломать.

## Разработка

```sh
npm ci
npm test
npm run typecheck
bb plugin install .   # первый раз
bb plugin reload sidebar-button
```
