# Resume Interrupted

After BB restarts, the Resume Interrupted plugin sends «продолжи» to each
visible, user-owned thread whose turn the host-daemon restart interrupted
within the last 6 hours. If you receive that message right after an
interruption, pick up the interrupted task where it stopped: check what was
already done before repeating side effects. The plugin has no commands.
