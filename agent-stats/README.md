# Agent Stats (BB plugin)

Карточка «сколько сессий и токенов ушло на агентов» в стиле постера Social Board: сторис 1080×1920, пост 1080×1350, квадрат 1080×1080, светлая или тёмная. PNG выгружается в 2× (2160×3840 для сторис): скачать, скопировать в буфер или «Поделиться» (системное меню; на iPhone через удалённый BB сразу в сторис).

Страница: **Agent Stats** в левом рейле BB (`/plugins/agent-stats/stats`). Период: последние 24 часа (по часам) или 7/14/30/90 календарных дней. CLI: `bb agent-stats show [--source bb|all] [--days N | --hours 24] [--json]`.

## Анимированные темы и видео

Шесть шейдерных тем — Закат, Зерно, Пиксели, Кислота, Нейросеть и Воронка — плавно движутся в предпросмотре. «Приостановить фон» останавливает движение; при системной настройке уменьшения движения фон изначально статичен. В скрытой вкладке и за пределами экрана анимация останавливается.

«Скачать видео · 15 сек» записывает карточку в выбранном формате (1080×1920, 1080×1350 или 1080×1080), без звука, с неподвижным текстом и анимированным фоном. MP4 выбирается при поддержке браузером, иначе WebM. Во время записи нужно оставить вкладку открытой; запись можно отменить. Видео доступно для шейдерных тем и требует MediaRecorder и canvas.captureStream. PNG/JPEG сохраняют текущий кадр, PNG по-прежнему доступен для копирования и системного меню «Поделиться».

## Виджет на рабочий стол

`widget/` — та же статистика как виджет macOS на рабочем столе: шейдерный фон из `shaders.tsx`, число токенов, сессии и разбивка по Claude Code и Codex. Размеры как у системных виджетов: маленький (170×170), средний (364×170), большой (364×382, с графиком по дням или часам).

Всё настраивается правым кликом по виджету: тема (шесть шейдеров), период (24 часа, 7/14/30/90 дней), источник (треды BB или все сессии), размер, анимация фона, «Поверх всех окон», «Запускать при входе», «Обновить», «Закрыть виджет». Виджет перетаскивается мышью, место и настройки запоминаются (`defaults read cc.bisovka.agent-stats-widget`).

Данные берутся из `bb agent-stats show --json` (через login-shell, как в Терминале) раз в 5 минут, после сна и при смене периода или источника. Фон анимируется на 30 кадрах в секунду (около 12% одного ядра) и останавливается, когда виджет закрыт окнами; без анимации нагрузки нет.

```sh
widget/build.sh   # собирает ~/Applications/Agent Stats Widget.app и перезапускает его
```

Нужны bun и Xcode Command Line Tools (swiftc). Удалить: «Закрыть виджет», снять «Запускать при входе», удалить приложение из `~/Applications`.

## Источники

- **BB.** Сессии = треды BB, созданные за период (включая архивные и скрытые). Токены: для каждого треда берутся ID его сессий провайдера (`thread/identity`), токены считаются по логам харнеса, `~/.claude/projects/**` (с сабагентами, дедуп по `message.id:requestId`) и `~/.codex/{sessions,archived_sessions}` (приращения `total_token_usage`). Если лога на этом Mac нет (архивный тред, другой хост), используются события BB `thread/tokenUsage/updated`. Они пишутся с 2026-10-10 и не на каждый ход.
- **Все сессии.** Все сессии Claude Code и Codex на этом Mac, включая BB. Токены и стоимость по прайсу API берутся из `codexbar cost --provider both --format json --days N` (CodexBar CLI), сессии считаются по файлам логов. За 24 часа CodexBar не годится (у него только дни): токены считаются прямо по логам, без цены. Результат кэшируется в памяти на 5 минут, «Пересчитать» обходит кэш.

Токены включают чтение кэша, как их считают CodexBar и провайдеры.

## Настройки

`bb plugin config agent-stats`: `handle` (подпись в шапке карточки, по умолчанию пусто, тогда в шапке «Agent Stats») и `codexbarPath` (по умолчанию `codexbar` из PATH, плюс `/opt/homebrew/bin`).

## Разработка

```sh
npm install
npm run typecheck
bb plugin build && bb plugin reload agent-stats
```

Шрифт: Geist (OFL), подмножество латиницы и кириллицы, встроен в `lib/fonts.ts` как woff2 data URL, поэтому PNG выглядит одинаково на любой машине. Знаки Claude/OpenAI взяты из Simple Icons (`lib/marks.ts`). Цвета провайдеров взяты из проверенного набора Social Board: Claude янтарный, Codex синий.
