# Сравнение диктовки: Whisper, GigaAM, Nemotron, SpeechKit

Дата: 17 октября 2026 года. SpeechKit установлен как плагин bb; его реальный
прогон заблокирован отсутствием API-ключа. Результат сравнения пока 3/4.

| Движок | Ошибки слов WER ↓ | Ошибки символов CER ↓ | Медиана ответа на запись | Ошибки запросов |
|---|---:|---:|---:|---:|
| GigaAM v3 E2E RNNT | **7,64%** | **3,73%** | **0,98 с** | 0/20 |
| Твой Whisper large-v3, полный | 9,18% | 5,42% | 1,66 с | 0/20 |
| Nemotron 3.5 ASR 0.6B, MLX BF16 | 13,39% | 6,01% | 1,28 с | 0/20 |
| Yandex SpeechKit v3 general | нет замера | нет замера | нет замера | нет API-ключа |

## Что проверено

Все 20 записей публичного тестового сплита
[bond005/podlodka_speech](https://huggingface.co/datasets/bond005/podlodka_speech).
Суммарно 486,51 секунды, то есть 8 минут 7 секунд. После единой нормализации —
1165 эталонных слов. Каждому движку передавались одни и те же WAV-файлы:
16 кГц, mono, PCM16. SHA-256 каждого файла сохранён в data/manifest.json и в
каждой строке результатов. Перед измерением каждого движка выполнен один
прогрев на первой записи. Веса не дообучались, текст эталонов моделям не давался.

Whisper — именно действующий домашний сервис на отдельном сервере, полный
`mlx-community/whisper-large-v3-mlx`, не Turbo. GigaAM — текущий движок bb
`v3_e2e_rnnt`, плагин 0.1.3. Nemotron —
`mlx-community/nemotron-3.5-asr-streaming-0.6b`, ревизия
`e550040c0478027ed679b2b6b0d055502c103663`, язык `ru-RU`, без квантования.
Для Nemotron использована уже существующая среда `~/.venvs/voicetry`,
mlx-audio 0.5.9, MLX 0.32.4. Модель скачана в стандартный HF-кэш.
Измерений через интерфейс MacWhisper или через Parakeet здесь нет.

## Как читать результат

GigaAM в этом прогоне допустила 89 ошибок слов, Whisper — 107, Nemotron — 156.
У GigaAM примерно на 16,8% меньше ошибок относительно Whisper, но это всего
18 ошибок на маленьком корпусе. Парный bootstrap по записям, 20 тысяч выборок,
seed=20261017: 95%-й интервал разницы WER GigaAM минус Whisper —
**от −3,46 до +0,74 процентного пункта**. Интервал включает ноль:
статистически уверенное превосходство над Whisper этим тестом не установлено.

Результаты относятся к этому корпусу. Это русские подкасты с отдельными
английскими терминами, не голос Евгения, не шумный микрофон и не весь спектр
диктовки. В эталонах есть особенности разметки; полная ручная переразметка
аудио не проводилась. Публичный тест не доказывает отсутствие пересечения с
обучающими данными моделей.

WER рассчитан через jiwer 4.0.0: NFKC, нижний регистр, ё→е, пунктуация и символы
заменяются пробелами, повторные пробелы убираются. **Числа и английские
транслитерации не унифицированы.** Например, «девяносто» и «90» считаются
разными словами. Поэтому WER включает часть отличий оформления. Пунктуация
не оценивается этой метрикой. Эти цифры нельзя напрямую сопоставлять с чужими
WER, рассчитанными с другой нормализацией.

Задержка — длительность реального запроса после прогрева, включая чтение
аудио/декодирование и транспорт. Whisper работает на домашнем сервере через Tailscale,
GigaAM — на CPU текущего Mac, Nemotron — на текущем Mac через MLX.
Текущий Mac — M3 Ultra, 96 GiB. Это сравнение работающих конфигураций,
а не скорости архитектур на одинаковом оборудовании. Суммарное время
распознавания: GigaAM 18,00 с, Whisper 49,76 с, Nemotron 26,74 с.

## SpeechKit: установлен, но без оценки качества

Плагин `speechkit@0.1.0` установлен в bb и зарегистрировал **Yandex SpeechKit v3**
в AI services. Текущий голосовой ввод остался GigaAM. Требуется ключ
сервисного аккаунта с ролью `ai.speechkit-stt.user` и действующим биллингом.
Ключ вводится в Settings → Installed plugins → Yandex SpeechKit → API key,
в защищённое поле. Ключ в чат отправлять не нужно.

Используется API v3 `general`, русский, пунктуация/нормализация включены,
литературное переписывание и фильтр мата выключены. Записи отправляются
в Yandex Cloud. Локальная интеграция проверена: сборка, TypeScript, тесты
на сохранение/обновление настроек, отсутствие ключа, пустой файл и замену
финальной гипотезы нормализованной без удвоения текста проходят.

Реальный TLS/gRPC-запрос с заведомо недействительным тестовым ключом дошёл
до Yandex и получил `UNAUTHENTICATED` за 0,50 с. Это проверка транспорта,
не успешного распознавания и не действующего доступа к сервису.

После настройки ключа тот же набор можно прогнать без повторного запуска
остальных моделей:

```sh
YC_API_KEY=<из защищённого окружения> .venv/bin/python benchmark/run.py --models speechkit
```

Никакие результаты SpeechKit в таблице не заимствованы из чужих бенчмарков.

## Артефакты

- `results/{gigaam,whisper,nemotron}.jsonl` — все 60 исходных ответов с эталонами,
  идентификаторами, хэшами WAV, длительностью аудио и временем ответа.
- `results/summary.json` — метрики и число замен, пропусков, вставок.
- `results/confidence.json` — парный доверительный интервал.
- `results/environment.json` — зафиксированные модели, версии и источники.
- `run.py` — повторный прогон и пересчёт.

Рекомендация по этому прогону: сохранить GigaAM текущим движком диктовки;
Whisper остаётся близким вариантом. Nemotron на данном материале дал больше
ошибок. Итоговый выбор среди четырёх отложен до реального прогона SpeechKit.
