# Copy Code

Tap or click any inline code in a bb chat message — a link, a command, a path
written in backticks — and its text goes to the clipboard. A short
«Скопировано» toast confirms it. Works in the desktop app and in remote access
from a phone.

Code blocks keep bb's own copy button; inline code inside links and editors is
left alone. Dragging to select text still selects; only a plain tap copies.

No settings, no commands.
