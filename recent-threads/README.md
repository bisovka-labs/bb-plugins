# Recent Threads

Плагин bb: второй вид списка тредов в сайдбаре — «Недавние».

## Что умеет

- **Переключение.** Кнопка с часами в футере сайдбара (или пункт в меню «···»),
  **⌘⇧R**, команда палитры «Список тредов: недавние / все» или кнопка «Все»
  сверху вида. Клавишу можно переназначить в Settings → Keyboard.
- **Только твоя работа.** Треды с твоими сообщениями за последние 1, 4, 12 или
  24 часа (по умолчанию 4). Архивные и скрытые треды не показываются.
  «Твоё сообщение» — запись в истории промптов bb (`bb prompt-history list`):
  сообщения из композера и стартовые промпты новых тредов. Сообщения агентов
  друг другу туда не попадают.
- **«Ждут тебя» сверху.** Треды, где агент задал вопрос, упал или закончил ход,
  который ты ещё не прочитал, собраны в первую группу, свежие сверху; справа —
  когда это случилось. Прочитанный тред остаётся в группе, пока ты в нём не
  ответишь, не снимешь ожидание или не заархивируешь его: случайно открыл и закрыл — он на
  месте. Подагент, в котором ты не писал, держится там, только пока открыт.
  При наведении на заголовок справа появляются две иконки: часы — общий
  список по времени, папка — разбивка по проектам (проект со свежим событием
  сверху). Выбор запоминается в этом браузере.
- **Снять ожидание.** Свайп вправо на телефоне или «Убрать из «Ждут тебя»»
  в меню треда перемещает его обратно в проект. Есть «Отменить». Снятие
  сохраняется в этом браузере; новое событие агента снова поднимет тред.
- **«Висят» снизу.** Неархивные треды без активности больше суток, которые не
  попали ни в окно, ни в «Ждут тебя»: старые и неразобранные сессии одной
  кучей, по всем проектам. Сверху — тред с самой свежей активностью, справа — сколько
  времени прошло («5 д»). Рядом с заголовком их число. Группа всегда
  открывается свёрнутой; развёрнутое состояние не запоминается. Разобрать тред —
  заархивировать его кнопкой на строке, тогда он пропадёт из группы.
- **Фокус на одном треде.** Кнопка-рамка на строке (видна при наведении,
  рядом с архивом) открывает тред и прячет все остальные: в сайдбаре
  остаётся только он и его подагенты, сверху плашка «Фокус». «Все треды»
  или та же кнопка возвращают обычный вид. Фокус запоминается в этом
  браузере и снимается сам, если тред заархивировали.
- **Проекты** по алфавиту, треды внутри — от свежего сообщения к старому,
  справа время твоего последнего сообщения. Группы сворачиваются кликом по
  заголовку; свёрнутая группа всё равно показывает открытый тред.
- **Подагенты под родителем.** Треды, которые запустил твой тред, лежат под ним
  свёрнутыми: кнопка с числом справа разворачивает их. Подагент, который ждёт
  тебя, поднимается в «Ждут тебя». Если открыт подагент, родитель
  разворачивается сам.
- **Черновики.** Тред с неотправленным черновиком попадает в вид с пометкой
  «черновик». У черновика нет своего времени, поэтому окно считается от
  момента, когда этот браузер его впервые увидел.
- **Новый тред в проекте.** Кнопка справа от названия проекта (видна при
  наведении) открывает экран нового треда с этим проектом в селекторе.
- **Как родной список.** Те же размеры, шрифты и цвета, оформление активной
  строки из темы, статус, кнопка архива при наведении (`bb--core/archive`),
  меню действий (кнопка и правый клик) и клавиатурные шорткаты bb.
- **Перетаскивание.** Строку можно утащить из сайдбара: к краю основной
  области — откроется сплит, в поле ввода чата — встанет упоминание треда.
  ⌘-клик открывает тред в сплите. Жест целиком обрабатывает bb
  (`experimental_useSidebarThreadSplit`).

## Как устроено

Переключатель пишет серверную настройку `sidebar.threadListProvider`:
`recent-threads/recent` или список, который был до этого (обычно
`thread-list/thread-list`). Поэтому переключение синхронизируется между всеми
окнами и телефоном. Окно в часах, свёрнутые группы, развёрнутые подагенты, тред в фокусе,
время черновиков и треды без ответа хранятся в localStorage браузера. Тред
без ответа забывается, когда в нём начался ход или в истории промптов
появилось твоё сообщение новее момента, когда он стал ждать.

История промптов читается целиком за сутки один раз, дальше — только самая
свежая страница, пока не встретится уже известная запись. Перечитывается,
когда какой-то тред начал ход или появился новый тред (то есть ты что-то
отправил), при возврате в окно и раз в минуту. Обычная работа агентов
запросов не вызывает.

Если `sidebar.threadListProvider` стоит в `__automatic__`, bb сам выберет
этот плагин как список по умолчанию (первый не встроенный). Чтобы по
умолчанию был родной список, закрепи его:
`bb settings ui set sidebar.threadListProvider thread-list/thread-list`.

Используются экспериментальные API (`experimental_threadList`,
`experimental_useSidebarThreadSplit`, `experimental_useThreadActions`,
`experimental_sidebarFooter`, `experimental_promptHistory`) и классы, по
которым тема красит строки bb. После обновления bb стоит проверить вид.

## Разработка

```sh
npm install
npm test            # логика (recent.test.ts) и рендер списка (app.test.tsx)
npm run typecheck
bb plugin install .   # первый раз
bb plugin build && bb plugin reload recent-threads
```
